# Results: perception-driven pipeline (legacy scene, weld-assist grasps)

Generated by `python scripts/results_table.py` from the JSON files in `results/perception/`. **Pour mode**: *held*, arm B holds the mug while arm A pours; *set-down*, arm B sets the mug at the pour spot, moves clear and re-grasps it afterwards. **Poses**: *perception*, object poses from the CNN on the overhead and front cameras (`models/perception/posenet_legacy.pt`); *ground truth*, poses read from the simulator. In both, whether a gripper holds something and the executor's success checks come from the simulator. Ranges are Wilson 95 % intervals. **Step-2 gate** (`gate_step2_calibrated_legacy.json`, rule: perception >= truth - 5 points and >= 75% on the same seeds): passed, pour mode set-down, perception 86 / 100 against ground truth 89 / 100 (3 points). Drawer-opening estimate at each release: median error 8.1 mm, max 25.2 mm over 102 releases.

CNN latency on the test run (two cameras, 717 estimates): median 15.4 ms, p95 28.9 ms.

**Step-1 perception gate** (`gate_step1_legacy.json`, rule: per object, over all visible dev samples: centre and grasp-point xy error, median <= 3.0 mm and p95 <= 6.0 mm): failed. Per object, grasp-point xy error median / p95 (mm): plate 2.6 / 5.5, mug 2.6 / 13.8, bottle 1.5 / 5.6, fork 4.6 / 29.4, spoon 5.0 / 26.9.

The strict droplet-pour metric (particles captured in the mug) is 0 % in every run above and is not used for success; a pour counts geometrically (see the README's Limitations).
